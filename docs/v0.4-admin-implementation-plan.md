## Boundaries

`apps/admin` calls `/api/admin/*` on the same NestJS API. A separate opaque,
HttpOnly, host-only Strict cookie resolves a live platform principal on every
request. `DATABASE_PLATFORM_URL` uses `vautrin_platform_admin`, never the
migration role and never BYPASSRLS. Customer users enter through the existing
one-time invitation flow; raw invitation tokens are returned once and are not
persisted in platform audit or browser storage. Tenant-facing authentication
rechecks account/membership/lifecycle state for immediate administrative revocation.
Production infrastructure is prepared here; live GCP apply and provider credentials
remain operator inputs, as in v0.3.
